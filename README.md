# 🏦 AI Voice ATM System

An advanced **Python-based ATM Simulation System** with voice assistance, secure authentication, transaction management, and a clean terminal UI.

This project is designed to simulate real-world ATM functionality while demonstrating Python programming skills, automation logic, and user interaction design.

---

## 📌 Project Overview

The **AI Voice ATM System** is a console-based banking application that replicates core ATM operations such as:

- Secure user authentication using PIN
- Balance inquiry and updates
- Cash deposit and withdrawal system
- Transaction history tracking
- PIN change functionality
- Voice-based feedback system

It uses **Text-to-Speech (pyttsx3)** to create a more interactive and realistic banking experience.

This project is ideal for beginners who want to understand:
- Python control flow
- Error handling
- User input validation
- Basic system design
- Real-world logic building
